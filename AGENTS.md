# Hugo starter instructions

Use Hugo Extended 0.167.0 and Node.js 22 or later. Run `npm run check` after changes.
Keep author settings in `hugo.toml`. Sample content and research records are fictional.
Keep the serif reading column, native controls, mobile navigation and reduced-motion support.
Preserve dates for copy-only changes. Use stable post slugs and descriptive image alt text.
Curate Related reading in `data/related-reading.json` with a content path, target ref and short context sentence.
Keep newsletter signup in demo mode until a real endpoint is configured. Analytics is disabled.
Never commit secrets, production content, personal identifiers or generated output.
